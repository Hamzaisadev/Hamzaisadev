# Assets

Every SVG and GIF in this folder is generated by the scripts in `src/`. Nothing is hand-exported.

- All type is outlined to vector paths, so it renders the same on every device without web fonts.
- Each asset comes in a `-light` and `-dark` version. The profile README uses `<picture>` to match the viewer's GitHub theme.
- All motion is CSS or SMIL inside the SVG and turns off when the viewer has *reduce motion* enabled.

## Rebuild

```bash
cd assets/src
npm i @fontsource/instrument-serif @fontsource/geist-sans @fontsource/geist-mono @fontsource/noto-nastaliq-urdu
pip install uharfbuzz fonttools brotli numpy pillow

python3 typeset.py         # converts the fonts into ./fonts

python3 gen.py ..          # all SVGs
python3 gif.py 360 ..      # dithered monogram GIFs
```

To change copy, such as the status board, project blurbs or toolbox, edit the data near the bottom of `gen.py` and rerun it.

Typefaces: Instrument Serif, Geist, Geist Mono and Noto Nastaliq Urdu, all SIL Open Font License.
